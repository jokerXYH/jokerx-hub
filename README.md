# Joker X · 中转站

一个苹果风的个人导航中转站。App 图标式卡片按分区排列，支持外链跳转和本地子项目跳转，带搜索、深浅色切换。

> **关于本仓库**：这是中转站前端本体的公开版本。`config.js` 里的链接为**示例数据**
> （工作/教务类地址已替换为 `https://example.com` 占位符），换成你自己的即可。
> `projects/` 下的本地子项目未包含在本仓库中，需要时把自己的项目文件夹放进去即可。

---

## 一、项目结构

```
jokerx-hub/
├── index.html        ← 唯一页面，结构与 DOM 骨架
├── style.css         ← 全部样式（浅灰底 / 白色卡片 / 深浅色切换）
├── config.js         ← 【唯一需要改的配置文件】条目数组
├── app.js            ← 交互逻辑：渲染卡片、搜索、分区、时钟
├── assets/           ← 图标与字体（icons/ 品牌图标、fonts/ 艺术字标）
├── README.md         ← 本文件（操作指南）
└── projects/         ← 本地子项目存放目录（本仓库未附带，按需自行放入）
```

**技术栈**：纯静态 HTML + CSS + JS，零构建、零框架、零依赖。改完直接刷新生效。

---

## 二、文件职责速查

| 文件 | 职责 | 改它的场景 |
|---|---|---|
| `index.html` | 页面骨架、DOM 结构、引用顺序 | 改页面结构、增减元素 |
| `style.css` | 全部视觉样式、CSS 变量、深浅色 | 改配色、布局、动效 |
| `config.js` | 链接数据数组 `LINKS` | **增删网站链接、分类**（最常改） |
| `app.js` | 渲染卡片、搜索、分区、时钟逻辑 | 改交互行为 |
| `projects/` | 本地子项目目录 | 往里放新网页项目 |

## 三、添加 / 修改网站链接

编辑 `config.js`，在 `LINKS` 数组里增删对象：

```js
{
  name: '网站名称',
  url: 'https://example.com',    // 外链：新标签打开
  desc: '一句话描述（可选）',
  mark: '网',                     // 无 logo 时显示的单字标识
  avatar: './assets/icons/xxx.svg',  // 可选：品牌图标（本地文件或图片 URL）
  cat: '常用'                     // 分类名，自动生成条目分区
}
```

### 外链 vs 本地项目

| 类型 | url 写法 | 打开方式 |
|---|---|---|
| 外部网站 | `https://...` 或 `http://...` | 新标签页打开 |
| 本地子项目 | `./projects/文件夹名/index.html` | 当前页打开 |

本地项目的文件夹放在 `projects/` 下（本仓库未附带，自行放入即可）。

### 分类

- 每个条目的 `cat` 字段决定它归属哪个分区。
- 分区标题（名称 —— 计数）**按 `LINKS` 数组中出现的顺序**自动生成，无需手动维护。
- 想调整分区顺序，调整数组中对应条目的顺序即可。

## 四、设计规范（接手修改时务必遵守）

### 4.1 视觉风格：苹果风（App 图标卡片）

- **底色**：浅灰 `--bg: #f5f5f7` + 白色卡片 `--card: #ffffff` + 近黑文字 `--ink: #1d1d1f`（次级 `#6e6e73` / 弱化 `#a1a1a6`）；深色 `#000` / `#1c1c1e` / `#f5f5f7`。
- **背景**：底色上叠一层极淡的顶部光晕（`--bg-glow`），让标题区透气；**不要彩色渐变、光斑图案、纹理堆叠**。
- **唯一强调色**：苹果蓝 `--accent: #0071e3`（深色 `#0a84ff`），只用于搜索聚焦光环、焦点描边和品牌圆点。**不要引入其他彩色**。
- **卡片**：16px 圆角 + 1px 细描边 + 极轻阴影；悬停上浮 2px、阴影略加深。**不要毛玻璃、彩色渐变、霓虹发光**。
- **字体**：正文用系统字体栈（SF / PingFang / 微软雅黑）；品牌字标 "Joker X" 用本地艺术衬线 **Playfair Display 斜体 600**（`assets/fonts/playfair-display-italic.woff2`，wght 400–900 变量轴），分区计数用同族常规体。**不要引 CDN 字体、不要给正文换艺术字体**。
- **图标规则**：卡片左侧 48px 圆角图标位，图标统一铺满图标位（App 贴片式，圆角贴合）：品牌彩色 logo / 站点 favicon 直接使用，本地项目无自带图标的用自绘渐变贴片（`assets/icons/`），都没有则显示 `mark` 单字兜底。**不要把 emoji 当图标或装饰**。

### 4.2 深浅色模式

- 通过 `<html data-theme="light|dark">` 属性切换，**有手动切换按钮**（顶栏右上角的日/月图标）。
- 首屏防闪：`index.html` `<head>` 里有内联脚本，在样式表加载前就读 `localStorage.jx_theme` 并设置 `data-theme`。
- 切换逻辑在 `app.js` 的 `bindTheme()`，状态存 `localStorage.jx_theme`（值为 `light` 或 `dark`）。
- 深色样式统一用 `html[data-theme="dark"] { ... }` 选择器覆盖 `:root` 变量，**不要再用 `@media (prefers-color-scheme: dark)`**。
- 默认（无 localStorage 时）跟随系统 `prefers-color-scheme`。

### 4.3 动效

- 卡片悬停（仅支持 hover 的设备）：上浮 2px + 阴影加深，`0.3s` 缓出；触屏点按用 `scale(0.99)` 轻反馈。
- 只保留必要的状态过渡（悬停、主题切换），**不要入场错峰动画**。
- **禁止**：鼠标跟随光晕、彩色描边渐变、霓虹发光、粒子特效、emoji 装饰。

## 五、本地预览

在项目根目录下启动任意静态服务器：

```bash
# Python 3
python -m http.server 8000

# Node（需安装 serve）
npx serve .
```

然后浏览器打开 `http://localhost:8000`。

> 现在是纯静态排版，没有 `backdrop-filter` 之类的特殊渲染，直接双击 `index.html` 用 `file://` 打开也能正常预览。

## 六、部署

整个 `jokerx-hub/` 文件夹直接上传到服务器根目录即可。无需构建步骤。

如果部署到子路径（如 `https://jokerx.top/hub/`），注意：
- `config.js` 里的本地项目相对路径 `./projects/...` 仍然有效（相对当前页面）。
- 子项目内部如果用了绝对路径 `/xxx`，需要改为相对路径或加上子路径前缀。

## 七、常见修改场景

### Q1：我想加一个新网站到「常用」分类
在 `config.js` 的 `LINKS` 数组里、「常用」分区中加一个对象，填好 `name/url/desc/mark/cat` 即可。

### Q2：我想加一个本地子项目
1. 把项目文件夹复制到 `projects/` 下，如 `projects/my-app/`。
2. 在 `config.js` 加一项，`url` 写 `./projects/my-app/index.html`，`mark` 填一个单字，`cat` 写 `'我的项目'`。

### Q3：我想调整卡片宽度 / 留白
改 `style.css` 里 `.app` 的 `max-width`（默认 `1000px`）和 `.card-grid` 的 `minmax(340px, 1fr)`，以及 `.card` 的 `padding` 和 `gap`。

### Q4：我想换强调色
改 `style.css` 里 `:root` 的 `--accent`，深色模式在 `html[data-theme="dark"]` 里同步改 `--accent`。

### Q5：我想加一个新功能（如标签收藏、最近访问）
- 纯展示/交互逻辑写在 `app.js` 里。
- 如果涉及新的数据（如收藏列表），优先在 `config.js` 或 `app.js` 顶部定义，不要污染 `index.html`。
- 样式加到 `style.css`，保持苹果风，遵守第四节设计规范。

---

## 八、注意事项

1. **不要引入构建工具**（Webpack / Vite / React 等），保持纯静态。
2. **不要引入外部字体**，用系统字体栈。
3. **不要加花哨特效**（霓虹、粒子、彩色渐变），不要用 emoji 当图标（条目用 `mark` 单字或品牌 logo，界面元素用 SVG/文字），保持克制。
4. 改完 `config.js` 只需刷新页面；改 `style.css` / `app.js` 也只需刷新（无缓存问题，除非服务器设了强缓存）。
5. 本地子项目的资源引用建议用相对路径，避免部署到子路径时失效。
